# Car Rental Dashboard

Lightweight Django operations panel for a vehicle-rental business.

## Features
- fleet management
- customer records
- rental lifecycle
- vehicle availability calendar
- demo-data seeding command
- Django admin for back-office operations

## Stack
Python 3.13, Django 5, SQLite for local/demo use.
